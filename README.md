# Practical Explorer — 실용적인 탐색가 퍼스널 브랜딩 웹사이트

> **"궁금한 것을 탐색하고, 더 나은 선택을 만듭니다."**  
> 일상에서 발견한 질문부터 새로운 경험과 지식까지. 직접 알아보고, 비교하고, 경험하며 나만의 관점을 만들어 가는 개인을 위한 퍼스널 브랜딩 웹 애플리케이션입니다.

---

## 1. 프로젝트 특징

- **무설치 & 노빌드(Zero-Build)**: 별도의 Node.js, Vite, Next.js나 로컬 웹 서버 실행 없이 **`index.html` 파일을 더블 클릭하는 것만으로 100% 정상 작동**합니다.
- **클라이언트 완결형(Offline-Ready)**: 모든 데이터 렌더링, 필터링, 모달 뷰어 및 개인화 기능이 방문자의 PC 브라우저 내부에서만 안전하게 실행됩니다.
- **그리스 산토리니(Santorini) 화이트 & 블루 디자인 시스템**: 눈부신 지중해의 맑은 오프화이트(`#F8FAFD`)와 순백(`#FFFFFF`), 코발트 블루 돔과 에게해의 맑은 바다빛 포인트(`#0066CC`), 깊은 밤바다 딥 네이비 섹션(`#0A192F`)으로 청량하고 품격 있는 무드를 연출합니다.
- **과장 없는 진정성**: 증명되지 않은 허위 경력이나 성과를 날조하지 않고, 탐색의 과정과 사고방식, 관심사, 실제 기록에 집중합니다.

---

## 2. 바로 실행하는 방법

1. 탐색기에서 프로젝트 폴더(`c:\AI_study\wep3`)를 엽니다.
2. **`index.html` 파일을 마우스로 더블 클릭**합니다.
3. Chrome, Edge, Whale 등 기본 웹 브라우저에서 즉시 웹사이트가 실행됩니다.

## 4. 내 정보(이름, 이메일, 저널)로 개인화하는 방법

### 방법 A. 웹 화면에서 실시간으로 설정하기 (가장 쉬운 방법)
1. 브라우저 우측 상단의 **`[내 정보 설정]`** 버튼을 클릭합니다.
2. 본인의 이름, 이메일 주소, GitHub/블로그/LinkedIn URL을 입력합니다.
3. **`[저장하기]`**를 누르면 사이트 전체의 `[이름]`과 연락처가 본인의 정보로 즉시 변경됩니다.
4. 이 정보는 브라우저 내부(LocalStorage)에 안전하게 보관되어 브라우저를 닫았다가 다시 열어도 유지됩니다.

### 방법 B. 코드 파일에서 영구적으로 설정하기
- **프로필 정보 수정**: `js/data.js` 파일 상단의 `profile` 객체 내용을 수정합니다.
  ```javascript
  profile: {
    name: "홍길동", // 기본값 [이름] 대신 본인 실명 입력
    contact: {
      email: "hello@example.com",
      github: "https://github.com/myaccount",
      blog: "https://velog.io/@myaccount",
      linkedin: "https://linkedin.com/in/myaccount"
    }
  }
  ```
- **탐색 기록(글) 추가 및 수정**: `js/data.js` 파일의 `journals` 배열에 새로운 글 객체를 추가하거나 기존 샘플 글을 본인의 실제 탐색 경험으로 교체할 수 있습니다.
